# 🧮 UNTRUSTY – The Calculator That Lies Half the Time

**UNTRUSTY** is a fun and interactive web-based calculator that intentionally gives incorrect mathematical results. Instead of performing normal arithmetic operations, it swaps every operator with its opposite operation.

For example:
- Addition (+) performs Subtraction (-)
- Subtraction (-) performs Addition (+)
- Multiplication (×) performs Division (÷)
- Division (÷) performs Multiplication (×)

The project demonstrates how JavaScript can be used to create interactive web applications with a unique and playful concept.

## ✨ Features

- 🎨 Modern and attractive dark-themed UI
- 🧮 Interactive calculator keypad
- 🔄 Every operator performs the opposite operation
- ⚡ Real-time input and result display
- 🚨 Glitch animation when calculating
- 🔴 Visual warning when the calculator gives a fake result
- 📱 Responsive layout
- 🧹 Clear button to reset the calculator
- ❌ Error handling for invalid mathematical results

## 🧠 How It Works

The calculator uses JavaScript to replace normal mathematical operations with opposite operations.

| Operator | Actual Operation |
|---|---|
| + | Subtraction |
| - | Addition |
| × | Division |
| ÷ | Multiplication |

Example:

```text
Input: 10 + 5
Actual Result: 5

Input: 10 × 5
Actual Result: 2
```
